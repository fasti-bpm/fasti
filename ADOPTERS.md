# Adopters

Organizations that use Fasti BPM, listed at their own request. [Tiếng Việt](ADOPTERS.vi.md)

Using Fasti BPM? Tell us and you are added here:

- **[Open an adopter issue](https://github.com/fasti-bpm/fasti/issues/new?template=adopter.yml)**
  (a short form), or open a pull request that adds a row to the table below.
- **Not allowed to be named in public?** Write to contact@fasti.dev. We list you without your name
  (for example "a bank in Vietnam") or not at all, as you prefer.

## Rules

- **Only by request.** An organization is listed only when someone authorized to speak for it
  asks. We do not add organizations we merely know or suspect to be users.
- **Logos only with permission.** A logo appears on the README or on [fasti.dev](https://fasti.dev)
  only if the form or a written message says so. Otherwise the entry is text only.
- **Removal at any time.** Open an issue or a pull request, or write to contact@fasti.dev, and the
  entry is removed without questions.
- **Stage stated honestly:** *Evaluating*, *Pilot* or *Production*. Update it when it changes.
