Giao diện web / Web UI

Theo dõi và vận hành quy trình, xử lý công việc, quản lý người dùng. Khi engine chưa có quản trị viên, giao diện web mở trang thiết lập để tạo quản trị viên đầu tiên.

Monitor and operate processes, work on tasks, manage users. As long as the engine has no administrator, the web UI opens the setup page to create the first one.

Mở giao diện web / Open the web UI

REST API

/engine-rest. Cần đăng nhập (HTTP Basic) bằng một người dùng của engine; chỉ danh sách engine là mở (xem README.txt).

/engine-rest. Requires HTTP Basic authentication with a user of the engine; only the list of engines is open (see README.txt).
